Como incluir alguém novo

Criar e apagar a conta em si exige uma chave que dá acesso total ao banco. Essa chave não pode existir num site publicado, porque ficaria visível para qualquer visitante. Por isso a conta nasce fora daqui e o acesso é dado aqui.

  1. Crie a conta no painel do Supabase em Authentication → Users → Add user, marcando Auto Confirm User. Use o e-mail de verdade da pessoa, o que ela lê no celular — é por ele que chega o link quando ela esquecer a senha.
  2. O nome aparece nesta lista como cliente.
  3. Você muda o perfil para admin ou dono.

Quem esquecer a senha resolve sozinho pelo Esqueci minha senha na tela de login. Você só precisa entrar no Supabase se a pessoa perder o acesso ao próprio e-mail.

Para tirar o acesso de alguém, devolva o perfil para cliente. Vale na hora: sem o perfil, o banco recusa qualquer leitura ou alteração do painel, mesmo que a pessoa esteja com a sessão aberta.
